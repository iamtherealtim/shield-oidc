# Security policy

This package handles sign-in, so security reports get priority.

## Reporting a vulnerability

Please **don't** open a public issue. Use GitHub's private reporting instead: the repository's **Security** tab, then **Report a vulnerability**. Include the version, your provider (Entra, Okta, …) and steps to reproduce.

You'll get an acknowledgement within a few days. Fixes are released as soon as they're ready, with credit in the changelog unless you'd rather not be named.

## Supported versions

Security fixes go into the latest release.
